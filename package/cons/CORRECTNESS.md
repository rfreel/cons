# Correctness boundary

LAWS.bend states three fixed outcomes. PROOF.bend must close them using the
exported implementation. The source fact comes from Amendment XXI, Section 1:
https://constitution.congress.gov/constitution/amendment-21/

The historical-presence result checks membership of A18 in this fixed model;
it does not prove retention of constitutional text. A successful Bend check
establishes those laws relative to Bend's checker and compiler. Independent
external conformance needs the source comparison and a separate run of the
public calls. No check here establishes the behavior for arbitrary Relation
values or the compiler's correctness.
